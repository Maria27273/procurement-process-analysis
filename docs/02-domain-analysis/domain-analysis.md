# Domain Analysis

## 1. Описание предметной области

Закупочный процесс начинается с возникновения потребности в приобретении товара или услуги и включает формирование заявки, её проверку, согласование и дальнейшую передачу в отдел закупок.

В зависимости от характера закупки заявка может проходить разные этапы согласования. Это связано с тем, что для отдельных типов закупок требуется дополнительная проверка со стороны специализированных подразделений.

В рамках проекта рассматриваются три основных типа закупок:

* простые;
* IT;
* юридические.

## 2. Типы закупок

| Тип закупки     | Характеристика                                                        | Особенности маршрута                        |
| --------------- | --------------------------------------------------------------------- | ------------------------------------------- |
| **Простая**     | Стандартная закупка товара или услуги                                 | Базовый маршрут согласования                |
| **IT**          | Закупка оборудования, программного обеспечения или IT-услуг           | Требует дополнительной технической проверки |
| **Юридическая** | Закупка, связанная с юридическими условиями или договорными вопросами | Требует дополнительной юридической проверки |

### Простая закупка

Простая закупка не требует специализированной проверки и проходит базовый маршрут согласования.

### IT-закупка

IT-закупка предполагает дополнительную техническую проверку, поскольку для принятия решения необходимо учитывать технические характеристики приобретаемого продукта или услуги.

### Юридическая закупка

Юридическая закупка требует дополнительной проверки юридических условий. В зависимости от содержания заявки может потребоваться участие юридического отдела.

## 3. Бизнес-правила

В рамках рассматриваемого процесса определены следующие базовые правила:

**BR-01. Тип закупки определяет дальнейший маршрут заявки.**

**BR-02. Перед дальнейшим согласованием заявка должна пройти проверку на корректность и полноту заполнения.**

**BR-03. Если заявка заполнена некорректно, она возвращается инициатору на доработку.**

**BR-04. После исправления заявка повторно проходит проверку.**

**BR-05. Для отдельных типов закупок предусмотрены дополнительные этапы согласования.**

**BR-06. После прохождения необходимых согласований заявка передаётся в отдел закупок.**

## 4. Вывод

Предметная область включает несколько типов закупок, для которых предусмотрены различные маршруты обработки и дополнительные этапы согласования.

При дальнейшем проектировании целевого решения необходимо учитывать различия между типами закупок и соответствующие им правила маршрутизации.
